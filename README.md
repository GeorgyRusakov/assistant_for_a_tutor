# Assistant for a Tutor

Телеграм-бот для автоматизации работы репетитора: учёт занятий, расписание, финансы и статистика — всё в одном чате.

## О проекте

Бот создан в помощь репетиторам, чтобы не вести учёт вручную в блокнотах и таблицах. С его помощью можно:

- 👩‍🎓 **Вести учеников** — добавлять, редактировать и удалять карточки учеников;
- 📓 **Вести журнал занятий** — отмечать проведённые уроки, их статус и содержание;
- 🗓 **Составлять расписание** — планировать и просматривать занятия на неделю;
- 💰 **Формировать финансовую отчётность** — считать доход, вести статистику по оплатам и занятиям.

Бот написан на Python (aiogram 3 + aiogram_dialog), хранит данные в PostgreSQL и запускается в Docker.

## Стек технологий

- **Python 3.11**
- **aiogram 3** + **aiogram_dialog** — Telegram Bot API и диалоговые сценарии
- **PostgreSQL** + **psycopg** — хранение данных
- **matplotlib** — построение графиков для статистики
- **Docker / Docker Compose** — запуск и оркестрация сервисов

## Установка и запуск

### Требования

- [Docker](https://www.docker.com/) и Docker Compose (рекомендуемый способ запуска)
- Токен Telegram-бота, полученный у [@BotFather](https://t.me/BotFather)
- Рабочий SOCKS5-прокси (используется для подключения к Telegram API — актуально, если Telegram недоступен напрямую из вашей сети)

### 1. Клонирование репозитория

```bash
git clone https://github.com/GeorgyRusakov/assistant_for_a_tutor.git
cd assistant_for_a_tutor
```

### 2. Настройка окружения

Скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

И заполните переменные своими значениями. Большинство из них можно придумать самому (пароли для PostgreSQL, pgAdmin, Redis), но часть нужно получить извне:

| Переменная | Откуда взять |
| --- | --- |
| `BOT_TOKEN` | Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте выданный токен |
| `ADMIN_IDS` | Ваш числовой Telegram ID, его можно узнать, например, у [@userinfobot](https://t.me/userinfobot) |
| `IP_PROXY`, `PORT_PROXY`, `LOGIN_PROXY`, `PASSWORD_PROXY` | Данные вашего SOCKS5-прокси (нужен, если Telegram API недоступен напрямую из вашей сети); указываются провайдером прокси |

Остальные переменные (`POSTGRES_*`, `PGADMIN_*`, `REDIS_*`, `LOG_*`) можно оставить как в примере или задать свои значения — это локальные настройки для контейнеров.

> ⚠️ Файл `.env` уже добавлен в `.gitignore` — не коммитьте его с реальными значениями в репозиторий.

### 3. Запуск через Docker Compose (рекомендуется)

Запустите все сервисы (бот, PostgreSQL, pgAdmin):

```bash
docker compose up -d --build
```

После запуска бот подключится к Telegram и будет готов к работе. PgAdmin будет доступен на `http://localhost:5050` (порт задаётся переменной `PGADMIN_PORT`).

### 4. Запуск без Docker (локально)

1. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Поднимите PostgreSQL любым удобным способом и укажите его параметры в `.env` (для локального запуска замените `POSTGRES_HOST=postgres` на `POSTGRES_HOST=localhost`).

3. Запустите бота:

   ```bash
   python main.py
   ```
